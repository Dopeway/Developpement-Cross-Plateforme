# Développement Cross-Plateforme

Dépôt du projet Flutter de la matière **Développement cross-platform**.

Les règles obligatoires pour les agents IA et les contributeurs sont dans
[AGENTS.md](AGENTS.md). Le cahier des charges et le code de l'application seront
ajoutés ultérieurement.

## Vérifications prévues

Après l'initialisation de l'application Flutter :

```bash
flutter pub get
dart format --set-exit-if-changed .
flutter analyze
flutter test
```
